# Довідник архітектурних концепцій (Cheat-Sheet)

## 1. ADO.NET: Connected vs Disconnected Mode

### Зв'язний режим (Connected Mode):
- **Компоненти:** `SqlConnection`, `SqlCommand`, `SqlDataReader`.
- **Характеристики:** З'єднання відкрите під час читання, дуже швидкий доступ, мінімальне споживання оперативної пам'яті (потокове читання запис за записом).
- **Коли використовувати:** Великі вибірки даних, читання для генерації звітів, висока швидкість читання.

### Незв'язний режим (Disconnected Mode):
- **Компоненти:** `SqlDataAdapter`, `DataSet`, `DataTable`, `SqlCommandBuilder`.
- **Характеристики:** Дані вивантажуються в пам'ять клієнта, з'єднання закривається; користувач редагує дані офлайн, після чого зміни пачкою відправляються назад у БД.
- **Коли використовувати:** Інтерактивне редагування таблиць користувачем у DataGridView, офлайн-режим.

## 2. Архітектурний патерн MVP (Model-View-Presenter) у WinForms

```
   [ View (Form) ] <==== events / user input ===== [ User ]
         |   ^
   calls |   | updates via interface
         v   |
   [ Presenter ] <==== loads / saves data ====> [ Model / DB ]
```

- **View:** Реалізує інтерфейс `IView` (наприклад, `ILoginView`), містить тільки код відображення контролів та підписку на події. Не містить жодної бізнес-логіки.
- **Presenter:** Приймає інтерфейс `IView`, реагує на дії користувача, валідує дані та викликає сервіси/модель.
- **Model:** Дані, бізнес-правила та доступ до бази даних.

## 3. Сучасний WPF UI: Стилі та Анімації

- **ResourceDictionary:** Інкапсуляція кольорової палітри та стилів для повторного використання.
- **ControlTemplate:** Повна перебудова візуального дерева стандартних контролів (Button, TextBox) без втрати їхньої функціональності.
- **Storyboard & DoubleAnimation:** Плавні апаратні анімації розмірів і прозорості без навантаження на головний потік UI.
